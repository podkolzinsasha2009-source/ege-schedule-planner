# ХимБиоРус — планировщик годового курса ЕГЭ

Онлайн-версия: https://podkolzinsasha2009-source.github.io/ege-schedule-planner/

Расписание годового курса (биология, химия, русский) на одной доске: плашки перетаскиваются, отмечаются выполненными, поверх можно писать стилусом и вставлять фото. Всё синхронизируется между компьютером, планшетом и телефоном.

## Возможности

- **Доска расписания.** 12 периодов, 972 занятия, тесты и письменные ДЗ отдельными плашками. Перетаскивание мышью, а на сенсорном экране — долгим нажатием. Фильтры по предмету и типу, поиск, «Отложенные».
- **Стилус.** Ручка, маркер, ластик, ластик целых линий, нажим, толщина, цвета. Если найден стилус, ладонь и пальцы не рисуют. Два пальца — отмена, три — повтор, щипок — масштаб.
- **Фото.** Вставка из галереи, через Ctrl+V или перетаскиванием файла. Фото можно двигать, растягивать за углы, закреплять и удалять.
- **Синхронизация.** Комната по ссылке или QR-коду. Компьютер можно выключать: данные лежат в облаке.
- **Офлайн.** Сайт открывается без интернета, изменения отправятся, когда сеть вернётся.

## Как устроено

Статический сайт без сборки: GitHub Pages раздаёт файлы, данные хранятся в Firebase Realtime Database (бесплатный тариф Spark, без карты).

| Файл | Назначение |
| --- | --- |
| `index.html`, `styles.css` | разметка и стиль |
| `store.js` | хранилище: зеркало в IndexedDB, очередь записи и подписка на Firebase |
| `app.js` | доска, плашки, перетаскивание, фильтры, окна |
| `ink.js` | стилус |
| `photos.js` | фото на доске |
| `schedule_data.js` | исходное расписание из PDF (`build_dataset.py`) |
| `sw.js` | офлайн-кэш, сначала сеть |

Данные комнаты лежат в `/planner/<код комнаты>`:

- `items/<id>` — плашка (`date`, `order`, `completed`, …); у каждой своя запись, поэтому правки с разных устройств не перетирают друг друга;
- `strokes/<период>/<id>` — штрих в координатах доски шириной 1480 px, одинаковых на всех экранах;
- `images/<период>/<id>` — фото;
- `live/<клиент>` — штрих, который рисуется прямо сейчас;
- `presence/<клиент>` — устройства в сети.

Открытый период хранится только на своём устройстве и не синхронизируется.

Если сайт на устройстве «застрял» на старой версии, откройте его с `?reset=1` — кэш очистится, данные останутся.
